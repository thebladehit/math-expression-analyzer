# Аналізатор арифметичних виразів

Лексичний та синтаксичний аналізатор арифметичного виразу на Go.
Синтаксичний аналіз виконує кінцевий автомат, заданий таблицею переходів.
Результат — список знайдених помилок з позиціями.

## Запуск

```bash
go run .
```

## Що підтримується

- числа: `2`, `3.14`
- змінні: одна літера (`x`, `a`)
- функції: `sin`, `cos`, `abs`
- операції: `+ - * /`, унарний мінус (`-a`, `(-b)`)
- дужки `( )`

## Які помилки знаходить

- **на початку виразу** — `*a`, `)a`
- **у написанні** — `1.2.3`, невідомі символи (`@`), невідомі функції
- **у кінці виразу** — `a+`, `sin`
- **у середині** — `a++b`, `(a)(b)`, `2(a)`, `(*a)`
- **з дужками** — `((a)`, `a)`, `()`

## Як це працює

1. **Лексер** (`an/lexer.go`) розбиває рядок на токени: `CONST`, `VAR`, `FN`, `OP`, `UNARY_M`, `OB`, `CB` і `END` — маркер кінця виразу.
2. **Парсер** (`an/parser.go`) проганяє токени через кінцевий автомат. Таблиця переходів `стан × тип токена → наступний стан + помилка` лежить у `an/state.go`. Після помилки автомат продовжує роботу, тож знаходить усі помилки, а не лише першу.
3. **Дужки** перевіряються стеком позицій. Так видно, яка саме дужка не закрита.

## Приклад

```
  *a++b)
  ^  ^ ^
```
